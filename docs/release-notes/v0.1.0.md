# ConanDirectConnect v0.1.0

Initial public release.

## Highlights

- Supports `-ip` and `-domain` address modes with no built-in server target.
- Writes Conan Exiles restart-ticket state for automatic server entry.
- Starts the game through Steam with `steam://run/440900`.
- Leaves mod management to the official launcher and the game.
- Publishes the Windows executable inside a zip artifact instead of as a bare
  `.exe`.

## Validation

- Unit tests cover address selection, IPv4 validation, INI editing, and restart
  ticket generation.
- The Windows amd64 release zip was built from this repository.
